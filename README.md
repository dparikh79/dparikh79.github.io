# dparikh79.github.io

Personal portfolio for **Dhruvil Parikh**, robotics engineer working at the intersection of physical autonomy, computer vision, and applied AI.

**Live →** [dparikh79.github.io](https://dparikh79.github.io)

## Stack

Hand-built single-page site. No framework, no build step.

- Semantic HTML, modern CSS (custom properties, fluid type, grid)
- Variable fonts: Instrument Serif, Newsreader, JetBrains Mono
- IntersectionObserver for scroll-triggered reveal
- Hosted on GitHub Pages

## Structure

```
index.html         # full site, embedded CSS + JS
images/            # photos, logos, résumé, project thumbnails
```

## Local preview

```bash
python3 -m http.server 8000
# open http://localhost:8000
```
